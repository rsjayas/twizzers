# Tweezers

*Two bodies, one soul.*

Tweezers is for people who belong to someone else and want to express their gratitude and feelings, and to present something to their beloved one: write or AI-generate a poem, turn it into an animated video with music, and share it.

(The GitHub repository is named `twizzers`; the product name is **Tweezers**.)

Start with `CLAUDE.md`, `docs/ARCHITECTURE.md` and `docs/PROJECT_DISCUSSION.md`.
